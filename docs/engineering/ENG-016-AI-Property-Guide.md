# ENG-016

# AI Property Guide

Version 1.0

---

# PURPOSE

The AI Property Guide is the primary buyer experience within

PropertyPilot.

Rather than reading static property descriptions, buyers engage

with an intelligent guide capable of answering questions,

navigating the property, explaining features and tailoring the

experience to individual interests.

The guide reasons from the Digital Property Twin rather than

general knowledge.

Every answer is grounded in verified property intelligence.

---

# FIRST IMPRESSION

The guide welcomes the visitor.

Example

"Welcome to 5698 Lamplighter Drive.

I'm your PropertyPilot guide.

I can answer questions, explain the home, walk you through

individual spaces, compare features and help you learn about

this property.

Where would you like to begin?"

# RESPONSE STRUCTURE

Every answer should include

Direct answer

Optional supporting detail

Relevant follow-up suggestion

Example

"Yes.

The workshop is insulated and heated using a forced-air

system.

It also includes both 120-volt and 220-volt electrical

service, making it suitable for woodworking, automotive work

or other high-power equipment.

Would you like me to explain the workshop's electrical

system next?"

---

# BUYER CONTROLS

Interrupt AI.

Skip topics.

Ask follow-up questions.

Jump between Assets.

Repeat answer.

Slow speech.

Fast speech.

Switch language.

Switch text/voice.

Bookmark information.

Share links.

Download brochure.

Request showing.

Save favorite Assets.

---

# AI BEHAVIOR

Never invent facts.

Never speculate.

State uncertainty clearly.

Explain confidence when asked.

Suggest follow-up questions.

Recommend related Assets.

Remain conversational.

Avoid repetitive phrasing.

# KNOWLEDGE GAPS

# EVIDENCE MODE

Buyer may ask

"How do you know that?"

The guide responds

"This information comes from the homeowner's verified

documentation and recorded property walkthrough."

When appropriate, show

Supporting photographs

Relevant documents

Timeline entries

# ACCESSIBILITY

Screen reader support.

Keyboard navigation.

Closed captions.

High contrast mode.

Adjustable font size.

Speech rate control.

Multiple languages.

---

# LEAD CAPTURE

Offer naturally.

Examples

Would you like a copy of the workshop specifications?

Would you like me to email today's brochure?

Would you like to schedule an in-person showing?

Capture only necessary information.

Never interrupt the conversation unnecessarily.

---

# SAFETY

Never answer legal questions.

Never answer financial questions beyond verified property data.

Never speculate regarding future values.

Never disclose private seller information.

Never expose internal notes.

---

# PERFORMANCE TARGETS

First response

<2 seconds

Follow-up response

<1 second

Navigation

<500ms

<200ms
