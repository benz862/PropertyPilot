# ENG-020

# Digital Property Twin Explorer

Version 1.0

---

# PURPOSE

The Digital Property Twin Explorer provides a complete,

interactive representation of every property managed within

PropertyPilot.

It is the central interface for understanding, exploring,

maintaining and presenting property knowledge.

Rather than viewing disconnected records, users navigate an

interconnected knowledge graph representing the entire property.
