# PropertyPilot

## PRD-020

# Enterprise & Brokerage Platform

Version: 1.0

Status

APPROVED

Priority

ENTERPRISE

####################################################################

VISION

####################################################################

PropertyPilot is designed for both independent realtors and

large brokerages.

A brokerage should be able to onboard hundreds or thousands of

agents while maintaining centralized branding, governance,

reporting, security and billing.

The enterprise platform must support growth without changing

the core architecture.

SUCCESS

A brokerage should be able to deploy PropertyPilot across

an entire organization with centralized management while

allowing every agent to maintain their own property portfolio.

Enterprise capabilities should extend the platform without

changing the individual agent experience.
