# Product Philosophy

PropertyPilot should feel effortless.

The software should disappear.

The buyer should focus on the home.

The realtor should focus on selling.

The AI should handle everything else.

Every screen must answer one question:

"What is the user trying to accomplish right now?"

If a screen has more than one primary purpose,

it should be redesigned.
